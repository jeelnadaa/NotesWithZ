# Syncscribe 🌙

> Created with **Kiro IDE** ✨

Yo, welcome to **Syncscribe**! This is the notes app that actually passes the vibe check. No database, no login, just pure browser storage magic. 💅

## Features 🚀
- **Aesthetic UI**: It's giving visuals. Clean, minimal, and aesthetic.
- **Rich Text**: 🅱️old, *Italic*, lists, whatever you need to spill the tea.
- **Secure**: Everything stays in your browser's local storage. We don't see your data, no cap. 🔒
- **Sticky Notes**: Color code your thoughts because organization is key. 🔑

## How to Run 🏃‍♂️

Literally so easy, just run these commands:

1. **Install dependencies** (don't ghost this step):
   ```bash
   npm install
   ```

2. **Start the vibe** (dev server):
   ```bash
   npm run dev
   ```

3. Open the link (probably `http://localhost:5173`) and you're good to go! 🎧

- React ⚛️
